# Exercise demo clips

Drop a clip here named **exactly** after the exercise id, and it auto-appears
in the app (Day screen + Library), playing **inside FORGE** — no YouTube, fully
offline. Supported: `.mp4`, `.webm`, `.gif`. Square-ish (1:1) clips look best.

Example: `d1-incline-db-press.mp4`
