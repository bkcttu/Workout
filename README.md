# FORGE — Personal Workout Tracker

An offline-first, installable **Progressive Web App** for a single user. Holds the
training program, logs weight + reps per set, remembers last session's numbers,
runs a rest timer, and tracks hydration, protein, supplements, and bodyweight.
No login, no backend, no App Store — **all data lives on your device** in
`localStorage` (`forge.v1`).

Rename the app in one place: `APP_NAME` in `src/data/plan.ts`.
Tweak the whole program in that same file.

## Stack

React + Vite + TypeScript + Tailwind CSS, `vite-plugin-pwa` for the manifest +
service worker. Zero runtime network calls.

## Run locally

```bash
npm install
npm run dev        # dev server (http://localhost:5173)
npm run build      # production build into dist/
npm run preview    # serve the production build locally
```

## Verify offline

1. `npm run build && npm run preview`
2. Open the URL once (service worker installs + precaches).
3. Kill your network / go offline.
4. Reload — the app still opens, and any logged data persists.

## Deploy (free HTTPS — required for iPhone install)

The app is a static site; deploy the `dist/` folder anywhere with HTTPS.

**Vercel**

```bash
npm i -g vercel
npm run build
vercel deploy --prod ./dist
```

**Netlify**

```bash
npm i -g netlify-cli
npm run build
netlify deploy --prod --dir=dist
```

Either command prints your final HTTPS URL.

> Note: this build was produced in a sandbox without deploy credentials, so the
> live URL is generated by *you* running one of the commands above. Everything
> needed to deploy is committed.

## Install on iPhone

1. Open the deployed HTTPS URL in **Safari** (must be Safari, not Chrome).
2. Tap the **Share** button (square with the up arrow).
3. Tap **Add to Home Screen**.
4. Launch FORGE from the home screen — it opens full-screen (standalone) and
   works offline from then on.

## Data model & backup

All state lives under the single key `forge.v1`. Use **Reference → Export JSON**
to download a backup and **Import JSON** to restore it on a new device.
